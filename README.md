Consegna – Gestione Rubrica Telefonica in Java

Realizzare un’applicazione in Java per la gestione di una rubrica telefonica.

Ogni contatto è caratterizzato dai seguenti attributi:

1. [x] Nome
2. [x] Cognome
3. [x] Numero di telefono

I dati devono essere memorizzati utilizzando tre liste accoppiate, una per ciascun attributo (nome, cognome e numero di telefono).

L’applicazione deve permettere di eseguire le seguenti operazioni:

1. [x] Aggiungere un contatto alla rubrica.
2. [x] Eliminare un contatto esistente.
3. [X] Modificare i dati di un contatto.
4. [ ] Cercare un contatto tramite:
   1. [ ] nome,
   2. [ ] cognome,
   3. [ ] numero di telefono.
8. [x] Visualizzare una lista parziale dei contatti filtrando per lettera iniziale del nome o del cognome.
9. [x] Stampare l’intera rubrica mostrando tutti i contatti salvati.
10. [ ] Ordinare la rubrica in base a:
    1. [ ] nome,
    2. [ ] cognome,
    3. [ ] numero di telefono.

L’interfaccia del programma può essere realizzata tramite menu testuale da console.
